# Couronne

Couronne est un tableau de bord de développeur pour le bureau : une bulle flottante qui ouvre un panneau avec les outils du quotidien (projets, ports, utilitaires, GitHub, Docker…).
Application Electron + React + TypeScript, locale (aucun compte, aucune télémétrie) et multiplateforme.

Pour plus d'informations sur l'architecture et les spécifications, consultez [`docs/BRIEF.md`](docs/BRIEF.md) et [`AGENTS.md`](AGENTS.md).
